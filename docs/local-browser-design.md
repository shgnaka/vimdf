# ローカル一覧のデザイン案 v2

整理日：2026-10-10。機能は [一覧 UI・キー・CSS 仕様](local-browser-ui.md) と [フォルダ管理](local-folder-management.md) を継承する。v2 は利用者が指定した全表示文字の同一サイズとボタンの表示設定を反映し、本番へ接続する。見本全体の利用者確認は未完了で、「全デザイン承認済み」とは扱わない。

## 範囲と参照元

独立した拡張ページは src/viewer/viewer.html、src/options/options.html、src/local-browser/browser.html の 3 種類。ファイル選択と登録済みフォルダ一覧は最後の 1 ページの状態であり、新しい URL やタブを増やさない。「フォルダ追加」は専用ページを作らず、既存のブラウザ / OS 標準 picker を開く。

Viewer と Options は現状を採用する。Options の Local PDF browser 節にボタン表示のチェック項目だけを追加する。通常・ローカル PDF 表示、アウトライン、Finder、本文検索、マーク、リンクヒント、保存、PDF パスワード入力、Viewer のヘルプ・通知・ローカルファイル案内、Options 内の保管庫作成・解錠・マスター変更・移行・出力・復元・初期化ダイアログも変更対象外。既存ページの配色・ステータス行・文字・ボタン・ダイアログを参照し、一覧の側を合わせる。

参照コードは 52097597734a83dc4eb2dac1cc038ad78e1bf2eb。Viewer の暗色 #1e1e1e / #e0e0e0、ステータス #252525、明色 #f5f5f5 / #1a1a1a を継承する。選択マーカーは #ff5a3c、フォーカスは #7aa2f7 / #0066cc。ボタンの 4 px の角丸と控えめな枠は Options、確認ダイアログの 24 px 内側余白と 10 px の角丸は既存 Viewer のダイアログを参照する。

## レイアウト

単一の一覧を画面幅いっぱいに使う。分割ペイン・常設サイドバー・カード一覧は追加しない。上部は現在位置と小さな Registered folders / Add folder 操作、中央は名前中心の一覧、下部は Viewer と同じ高さを基準にしたステータス行とする。両ボタンは初期表示し、Options で個別に隠せる。隠しても r / a と ? のヘルプは使える。VimDF ロゴ、Settings、常設検索、常設キー説明を出さない。

| 部分 | 採用値・表示 |
| --- | --- |
| 上部 | 左右 24 px、上下 12 px。最低 52 px、長い位置名は折返して拡張 |
| 現在位置 | 13 px 等幅。登録名と相対位置。未登録の親や OS 全体のパスを推測しない |
| 一覧 | 左右 24 px。行の内側左右 12 px、最低 32 px。本文・補助情報・ID もすべて 13 px |
| 列 | 名前を可変幅、Type を 66 px。登録一覧だけ Default と Remove を追加 |
| 選択 | 行の塗り + 左 3 px のマーカー。丸いカード・影を付けない |
| 既定 | 保存済み primary に Default。選択カーソルと独立 |
| ステータス | 最低 24 px、左右 12 px、13 px 等幅。状態・現在位置・選択位置 / 表示件数・確定した絞り込み |
| 一時入力 | / の間だけステータス直上。文字・モードラベルとも 13 px。終了後は隠し、検索語はステータスへ残す |
| ボタン | 等幅 13 px、余白 6 / 12 px、角丸 4 px、細い枠 |
| ダイアログ | 解除は最大 480 px、一覧ヘルプは最大 760 px。左右 20 px を残す。見出し・説明・キー・入力は 13 px |
| 説明 / エラー | 13 px 等幅。空・未登録・許可・競合・保存失敗でもサイズを揃える |

見本は 960 × 540 px を基準とするが、本体をこの寸法へ固定しない。650 px 以下では位置と操作を縦に並べ、左右余白を 16 px にする。登録一覧では Type を先に隠して名前・Default・Remove を保持する。長い名前と同名識別用 ID は折返し、必要に応じて行を伸ばす。Tab で触れる Remove を省略せず、320 px でも操作を横にはみ出させない。タッチではボタンを最低 44 px に広げる。

本体の字体は既存 system monospace を使い、追加 Web フォントを読まない。Figma には Consolas / Menlo / Liberation Mono がないため、見本だけ Roboto Mono を代用する。日本語注釈は Noto Sans JP。字体の完全一致を確認したとは主張しない。

ターミナルらしさは全表示文字の基準サイズを揃えることで表現する。見出しや重要メッセージの強調は太さ・色・余白・枠で行う。狭い幅やタッチでも入力文字だけ大きくしない。Custom CSS で .vimdf-browser のサイズを変えれば見出し・補助表示・入力・一覧ヘルプも継承する。Viewer の既存 statusBarFontSize は一覧へ適用しない。

既存 Dark / Light / Auto を継承し、一覧専用のテーマ設定やテーマ切替を増やさない。Custom CSS と公開変数 9 個の優先順位を維持する。橙色は細い選択マーカーを中心に使い、大きな背景を塗らない。明色ヘルプのキー文字は青を使う。

本体へ移す場合は規則を #files、.vimdf-browser、一覧の確認・ヘルプへ限定する。共有 viewer.css、options.css、.vimdf-viewer、Viewer の #help は変更しない。ページ全体への button / h1 / dialog 規則を追加して Viewer 側へ漏らさない。

## 全画面・状態の見本

独立ページに加え、dialog と例外状態も漏れなく扱う。

| 見本 | 対象 | 決定内容 |
| --- | --- | --- |
| D01 | ファイル選択 | 名前と Type の単一一覧。位置・選択・件数 |
| D02 | 登録一覧 | 登録順を維持。選択と Default を別表示。個別 Remove |
| D03 | フォルダ追加 | native picker 前の状態を保持。OS の窓を独自に描かない |
| D04 | 未登録・最後の解除後 | 小さな説明と Add folder。新しい歓迎画面は作らない |
| D05 | 権限確認・再許可 | 対象名・読取権限・Allow read access。他の登録・追加も選べる |
| D06 | 絞り込み中 | 下部入力だけ。通常画面の Enter と区別 |
| D07 | 空フォルダ | フォルダ / PDF がない説明。未登録とは別 |
| D08 | 結果なし・入力終了後 | 検索語と 0 件。存在しない項目の確定を案内しない |
| D09 | 登録復元・一覧処理中 | LOADING、操作禁止。未登録と表示せず既存行を保持 |
| D10 | PDF 読込中 | ローカルの既存 overlay と取消を採用。Viewer は変更しない |
| D11 | 許可拒否・読取 / 保存失敗 | エラーと Retry。元の位置・検索・選択・登録を保持 |
| D12 | 別タブ更新・保存競合 | 通知と Reload folders。登録を変える操作は止め、自動切替しない |
| D13 | 既定・非既定の解除 | 対象・次の既定または既定不変・保持データ。Keep folder を初期フォーカス |
| D14 | 最後の解除 | 0 件になる説明と再追加可能なこと。取消優先 |
| D15 | 一覧ヘルプ | Viewer と別の dialog。状態別の操作表・内部スクロール・検索 |
| D16 | ヘルプ検索・結果なし | 検索語と説明。背後の一覧・PDF を動かさない |
| D17 | DB 復元 / open / blocked / schema 失敗 | 初回登録を禁止。原因に合う再読込案内と利用可能な PDF 選択 |
| D18 | API 非対応 | フォルダ用操作・列・キー案内を出さず Open PDF file |
| D19 | 明色 | 既存テーマの同じレイアウト |
| D20 | 狭い幅・長い名前・同名 | 折返し・Type 省略・識別 ID・操作の縦配置 |
| D21 | private / iframe 起動 | 登録を読まず通常のトップレベルタブへ案内 |
| D22 | 破棄 PDF 履歴 | 再選択を通知し、一覧位置を保持 |

追加成功は登録一覧で新しい行、重複は既存行、取消は呼出元に戻る。権限のない追加登録は既存仕様に従って登録一覧へ残し、選択後に D05 を使う。初回の許可拒否を成功扱いしない。D02〜05 / D11 を再利用し、完了ページは追加しない。

解除はファイル削除ではなく登録解除と明記する。パスワード等の機密値をエラー・ラベルへ混ぜない。処理・取消・IME・入力・ヘルプのキー所有は既存 UX 契約を維持し、見た目の都合で機能を変えない。

## 見本と確認状況

[Figma の編集可能な見本](https://www.figma.com/design/p53tWnSW9kkHDSsTZfV1sx) は、通常の流れ、空・処理中・回復、ヘルプ・確認、テーマ・幅・起動停止の 4 ボード、22 画面。既存 Viewer / Options の Figma ファイルを変更していない。スクリーンショットの貼付ではなく、文字・行・ボタン・背景を編集できる初稿で、動作する拡張そのものではない。

構造・文字寸法・字体・画像 fill 不使用を確認し、ボード高と狭い幅の行高を修正した。最終ボードは 2016 × 1962 px が 3 枚、2016 × 1338 px が 1 枚。画像取得 URL はこの環境から利用できず、inline 取得も Starter の MCP 枠で拒否されたため、Figma の見た目の最終確認は未完了。会話内の画面切替見本と本仕様を併せて確認する。見本の配色・幅切替はレビュー用で、本体への追加操作ではない。

v1 のデザイン検討時点では Viewer / Options 配下 31 ファイルは未変更だった。v2 は一覧の文字サイズと表示設定を本番へ実装し、Options の HTML / TS にチェック項目を追加する。Viewer 配下と共有 viewer.css、options.css は変更しない。Figma は MCP 利用枠により v2 の文字サイズ変更を反映できておらず、v1 の見本のまま。サイズの現行仕様はこの文書と本番を優先する。自動検証は [テスト記録](local-browser-testing.md) に対象コミットと結果を残す。
